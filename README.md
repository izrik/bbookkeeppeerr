# bbookkeeppeerr

A bookkeeping and accounting system for businesses, built with a React frontend and Python FastAPI backend.

## Features

- User authentication (login/register)
- General ledger management
- Double-entry bookkeeping
- Account management (assets, liabilities, equity, revenue, expenses)
- Secure JWT-based authentication
- Modern React UI with Material-UI
- RESTful API with FastAPI

## Setup

### Prerequisites

- Python 3.11+
- Node.js 16+
- uv (Python package manager)

### Backend Setup

1. Navigate to backend directory:
   ```bash
   cd backend
   ```

2. Install dependencies with uv:
   ```bash
   uv sync
   ```

3. Set up environment variables (optional):
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. Run the backend:
   ```bash
   uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

The API will be available at `http://localhost:8000`

### Frontend Setup

1. Navigate to frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

The frontend will be available at `http://localhost:3000`

### Development (Both Services)

From the root directory, you can run both services concurrently:

```bash
npm run dev
```

## API Documentation

Once the backend is running, you can access the interactive API documentation at:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

## Database

The application uses SQLAlchemy with SQLite by default. The database file will be created automatically as `bbookkeeppeerr.db` in the backend directory.

To use PostgreSQL instead, update the `DATABASE_URL` environment variable:
```
DATABASE_URL=postgresql://username:password@localhost/bbookkeeppeerr
```

## Authentication

The system uses JWT (JSON Web Tokens) for authentication. Users must register and login to access the application. All API endpoints (except authentication) require a valid JWT token.

## Account Types

The system supports five types of accounts following standard accounting principles:

- **Assets**: Resources owned by the business
- **Liabilities**: Obligations of the business
- **Equity**: Owner's stake in the business
- **Revenue**: Income generated by the business
- **Expenses**: Costs incurred by the business

## Double-Entry Bookkeeping

Every transaction in the ledger follows the double-entry principle:
- Every debit must have a corresponding credit
- The total debits must equal the total credits
- This ensures the accounting equation (Assets = Liabilities + Equity) always balances

## Kubernetes Deployment

The application is designed to be deployed to Kubernetes. You'll need to:

1. Build Docker images for both frontend and backend
2. Create Kubernetes manifests for deployment, service, and ingress
3. Configure secrets for environment variables
4. Set up persistent storage for the database
